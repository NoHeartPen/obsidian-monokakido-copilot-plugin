# よくある質問

Q: 「物書堂で引きました」とは出るのですが、物書堂の方は反応せず。Copilot History の方には単語の履歴は残っています。セッティングに問題ありますかね？（Mac で使っています）

A: Mac での物書堂のセッティングで「クリップボード検索」を**有効**するようお願いします。

![クリップボード検索を有効する](../asset/01.png)

Q: 設定済みの辞書を新しい保管庫でも使うには、どうすればよいですか？

A: 元の保管庫の辞書設定をバックアップし、新しい保管庫で JSON を貼り付けるか、バックアップファイルを選択してインポートできます。

1. 元の保管庫でプラグインの設定を開き、「辞書リンクのバックアップ」を探します。
2. 「コピー」をクリックすると、設定が JSON テキストとしてコピーされます。テキストエディタに貼り付けて保存してください。または、「JSON をエクスポート」をクリックすると、元の保管庫のルートに `monokakido-dictionaries.json` として保存されます。同名のファイルがある場合は、ファイル名の末尾に数字が自動で追加されます。実際の保存先は、保存完了の通知で確認してください。
3. 新しい保管庫にプラグインをインストールして有効にし、プラグインの設定を開きます。
4. 「辞書リンクのインポート」で、「貼り付けてインポート」から JSON を貼り付けるか、「ファイルからインポート」からバックアップファイルを選択し、「インポート」で確定します。新しい保管庫のデフォルトの辞書と追加辞書は、バックアップの内容に置き換えられます。名前・URL・表示順は復元され、その他のプラグイン設定は変更されません。

インポート前に、現在の辞書設定を保存するか確認します。「バックアップしてインポート」を選ぶと、保管庫のルートに `monokakido-dictionaries-auto-backup-YYYY-MM-DD-HH-mm.json` を保存してからインポートします。日時はインポート時のローカル時刻で、分単位まで含まれます。

**エクスポートに成功したのに JSON ファイルが見つからない場合：** Obsidian では「すべてのファイル形式を表示」（Show all file types）が初期設定でオフになっているため、エクスポートした JSON ファイルがファイル一覧に表示されないことがあります。「設定 → ファイルとリンク（Files and links）」でこの項目をオンにするか、Finder やエクスプローラーなどのファイル管理アプリで、元の保管庫のルートを確認してください。

この項目をオンにするとファイル一覧に表示されますが、Obsidian で JSON の内容を直接表示できるようになるわけではありません。内容を確認するには、テキストエディタで開いてください。

![Show all file types](../asset/02.png)

バックアップに含まれるのは、デフォルトの辞書の URL と、追加辞書の名前・URL・表示順です。検索履歴やその他のプラグイン設定は含まれません。バックアップは保管庫の外にも保存しておくことをおすすめします。
